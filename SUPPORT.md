# Support

Codex Mantle is alpha software maintained by its community. Before requesting help, run
`codex-mantle doctor --json`, remove private paths and workspace content from the output, and check
the documentation and existing issues.

## Where to ask

- Reproducible defects: open a bug report with the smallest safe fixture and exact versions.
- Feature proposals: open a feature request describing the user problem and safety boundary.
- Usage questions: open a support issue; do not attach credentials, private instructions, generated
  schemas, or real workspace data.
- Vulnerabilities: follow [SECURITY.md](SECURITY.md) and use private vulnerability reporting, never a
  public issue.
- Conduct reports: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Support for an unlisted Codex release is read-only until its capability contract and acceptance
evidence are added. Maintainers cannot guarantee response times or recover data outside Mantle's
verified snapshots.
