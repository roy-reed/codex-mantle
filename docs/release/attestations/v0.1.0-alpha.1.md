## Known limitations

- This is an alpha release with profile writes gated to the tested Codex 0.147.x series.
- The local dashboard is read-only; mutations remain explicit CLI plan/apply operations.
- Plugin manifests are validated data contracts. Arbitrary third-party plugin code is not executed.
- Windows receives a release-archive installer acceptance gate; Linux and macOS receive the
  platform-independent repository check in CI.
